# Master Fontify 

مجموعة منتقاة واحترافية من الخطوط العربية والإنجليزية مفتوحة المصدر لمطوري Flutter. تم تصميم هذه الحزمة لتوفير الوقت والجهد، وتسهيل استخدام الخطوط الجميلة في التطبيقات بضغطة زر.

##  المميزات
- دعم كامل للخطوط العربية والإنجليزية.
- خطوط حقيقية مرخصة برخصة المصادر المفتوحة (OFL).
- سهلة الاستخدام عبر دوال جاهزة (TextStyles).
- لا تحتاج إلى إعدادات معقدة في ملف `pubspec.yaml` الخاص بتطبيقك.

##  التثبيت
أضف الحزمة إلى ملف `pubspec.yaml` في تطبيقك:

```yaml
dependencies:
  master_fontify: ^0.1.0
